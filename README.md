# grapevine-adna

This repo is for grapevine ancient-DNA methods: damage, authentication, aDNA-specific capture, and projection onto modern panels.

## This is not

This is not the modern 167K analysis product. Calling and ancestry reports live in [grapeancestry](https://github.com/Xuzhen-Li/grapeancestry).
This is not plastid-only assembly or phylogeny. That line is [grapevine-plastid](https://github.com/Xuzhen-Li/grapevine-plastid).
This is not chip design. Probe files live in [grapevine-chip](https://github.com/Xuzhen-Li/grapevine-chip).

- Not a modern 167K FASTQ-to-report suite
- Not a chloroplast pangenome
- Not a general popgen theory folder

## What will land later

Methods, scripts, and notes only.

- Damage and authentication checklists
- aDNA-specific capture notes
- Projection onto modern panels (methods, not sample matrices)

No unpublished genotypes, private coordinates, or sample-level matrices.
