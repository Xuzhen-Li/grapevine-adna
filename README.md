# grapevine-adna

Ancient-DNA methods and notes for *Vitis*: damage, authentication, aDNA-oriented capture, and projection onto modern panels.

**Status:** public placeholder. No pipeline, no plant-specific protocols, and no demo data here yet. Earlier checklist drafts were generic vertebrate aDNA recipes and were removed — they were not lab practice for this line.

## This is not

- Not the modern 167K product → [grapeancestry](https://github.com/Xuzhen-Li/grapeancestry)
- Not chip design → [grapeancestry/chip](https://github.com/Xuzhen-Li/grapeancestry/tree/main/chip)
- Not plastid assembly → [grapevine-plastid](https://github.com/Xuzhen-Li/grapevine-plastid)
- Not theory dossiers → [genomics-theory-mining](https://github.com/Xuzhen-Li/genomics-theory-mining)

## What belongs here later

Methods and notes only — when they are real for plant / grapevine aDNA — not unpublished genotypes or private site coordinates.
