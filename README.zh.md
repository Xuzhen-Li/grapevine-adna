# grapevine-adna

[English](README.md) | 中文

关于 *Vitis* 的古DNA方法和笔记: 损伤、鉴定、面向古DNA的捕获以及向现代面板的投射。

状态: 公开占位符。这里目前没有流程、没有植物特定的方案，也没有演示数据。早期的清单草稿是通用的脊椎动物古DNA配方并已被移除，因为它们不是本研究方向的实验室操作。

## 这不是

* 不是现代 167K 产品: [grapeancestry](https://github.com/Xuzhen-Li/grapeancestry)
* 不是芯片设计: [grapevine-chip](https://github.com/Xuzhen-Li/grapevine-chip)
* 不是质体组装: [grapevine-plastid](https://github.com/Xuzhen-Li/grapevine-plastid)
* 不是理论汇编: [genomics-theory-mining](https://github.com/Xuzhen-Li/genomics-theory-mining)

## 以后会包含什么

仅包含方法和笔记，在它们对于植物或葡萄古DNA切实可用时添加，不包含未发表的基因型或私有位点坐标。
